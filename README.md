## Install kaise karein

1. Upar se APK download karo.
2. Phone poochega "Install unknown apps", apne browser ya file manager ke liye **Allow** karo.
3. **Install** dabao. Pehle se Lumen hai to button **Update** dikhega, aur aapka data waise ka waisa rahega.

**1.2 se aa rahe ho?** Version 1.3 se app nayi pakki key se sign hota hai, isliye ek baar purana app hatana padega. Uske baad har update bina data khoye install hota hai. Hatane se pehle Settings mein backup file bana lo.
